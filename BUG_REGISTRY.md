| BUG-01 | CRITICAL | Network / Metro | App failed to connect on Android physical device, displaying white screen | Windows Metro bundler bound exclusively to IPv6 `::1:8081` when `--localhost` was used; ADB reverse tunnel forwards IPv4 `127.0.0.1:8081` | Launched Metro server with `--lan` bound to `0.0.0.0:8081`; configured `adb reverse tcp:8081 tcp:8081`. | BUG-04 | MEDIUM | Calculator Modal | Keypad button row overflow on compact Android screens | Keypad keys had fixed high pixel height causing submit button to be pushed below screen fold | Implemented responsive `ScrollView` wrapper and 44px keypad key height with quick amount chips | RESOLVED |

| BUG-07 | HIGH | Data Layer | Race conditions during rapid note and cashbox submissions | Concurrent async writes reading stale state snapshots | Implemented mutex write queue (`writeQueue`) in `storageRepository.js` guaranteeing serialization | RESOLVED |
